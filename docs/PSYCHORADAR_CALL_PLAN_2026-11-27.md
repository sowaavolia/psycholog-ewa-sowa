# PsychoRadar CALL — implementation plan

## Goal
Increase legitimate inbound calls to the psychology practice while controlling ad spend.

## Three stages
1. Configure local campaigns for Lębork and Wejherowo and an approved monthly/daily budget.
2. Publish approved posts to connected business pages; respect group rules and permissions.
3. Track consent-compliant call conversions, cost per qualified call, and pause/alert rules.

## MVP backlog
- Test website mobile phone CTA (+48 668 044 161) and disclosure/privacy text.
- Check mobile page interactions and expandable tiles.
- Build a small campaign configuration interface with budget and approval status.
- Integrate advertising APIs only after scopes and account permissions are confirmed.
- Never auto-publish into private groups or promise pay-per-call billing from ordinary click ads.

Status: planning file only; no automatic campaign manager deployed.
